# Bundled asset licences

Every bundled asset must be listed here with its source and licence before it ships.

| Asset | Source | Licence |
| --- | --- | --- |
| Procedural figures, chair, priority sign, test charts | Generated in code (`src/assets/procedural.ts`, `src/diagnostics/charts.ts`) | Original work, same licence as this repository |

No third-party models, textures or images are bundled as of M1.
Scanned models supplied by the user stay in the browser (IndexedDB) and are never redistributed.
